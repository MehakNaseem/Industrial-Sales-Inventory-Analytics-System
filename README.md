# Industrial Sales & Inventory Analytics System

## Overview
An end-to-end data analytics project simulating a real industrial company's business intelligence system. Built using PostgreSQL, Python, and Power BI.

## Tools Used
- PostgreSQL — database design and SQL analysis
- Python (pandas, psycopg2, seaborn, matplotlib) — data extraction and visualization
- Power BI — interactive business dashboard

## Database Structure
- suppliers — vendor information
- products — product catalog with cost and selling price
- customers — client details and segmentation
- inventory — stock levels and reorder alerts
- orders — all sales transactions

## Key Insights
- Identified top revenue generating customers
- Analyzed profit margins across product categories
- Tracked monthly sales growth trends
- Built inventory reorder alert system
- Customer segmentation (Retail, Wholesale, Corporate)

## Files
- connect.py — Python script for database connection and visualization
- Industrial_Analytics_Dashboard.pbix — Power BI dashboard

## Dashboard Pages
- Page 1: Sales Overview
- Page 2: Product & Profit Analysis
- Page 3: Inventory Status
